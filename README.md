# 拾光 · Image Studio

无需安装、无需构建的静态生图工作台。可部署到 GitHub Pages，在电脑或手机浏览器打开。前端直接连接用户指定的图片 API，没有中转服务器。

## 发布到 GitHub Pages

1. 新建 GitHub 仓库，把本目录的 `index.html`、`styles.css`、`app.js`、`api.js` 和 `.nojekyll` 上传到仓库根目录。
2. 打开仓库 Settings → Pages。
3. Source 选择 Deploy from a branch，Branch 选择 main，目录选择 / (root)，保存。
4. 部署后打开 Pages 显示的网址，一般是 `https://用户名.github.io/仓库名/`。
5. 点击「API 设置」，填写你自己的 API Key 并保存。默认服务为 `https://www.kuaiaiapi.com`，模型为 `gpt-image-2.5`。

请只上传本网页目录，不要上传旧项目中的照片、生成记录、密钥或配置备份。此网页目录没有密钥或私人照片。GitHub Pages 页面本身公开，访问者使用自己填写的密钥。

## 本地预览

在本目录运行 `python -m http.server 8765 --bind 127.0.0.1`，打开 `http://127.0.0.1:8765`。不要双击 index.html 使用 file:// 打开，浏览器的模块和存储需要 HTTP 或 HTTPS。

## 默认创作参数

常用比例按 16:9、1:1、3:4、2:3、9:16、3:2 排列，两行三列。对应请求尺寸依次为 2048×1152、2048×2048、1728×2304、1360×2048、1152×2048、2048×1360。默认选择 16:9、高质量、生成 1 张、并发 1。结果卡片显示实际返回尺寸，服务商可能缩小输出。

## 功能

- 默认文生图；拖入、粘贴、选择图片后自动切换为图生图，最多 16 张原图。
- 使用 multipart `image[]` 多图上传，可自定义字段。
- 可选背景、主体外观、风格标签：指定背景后只使用该图作场景参考；默认不追加约束。
- 1–20 张批量创作，1–6 路并发。直接图片响应和 task_id 轮询均支持。
- 自定义模型、尺寸、质量、路径、请求超时、轮询间隔及额外 JSON 参数。
- 大图预览、左右切换、单张重试、复用批次、用结果继续创作。
- 下载原图、复制图片、系统文件分享（取决于浏览器支持），Chrome/Edge 桌面端可选择目录并自动保存。
- 使用 IndexedDB 在当前浏览器保存历史、参考原图和生成原图。
- 浏览器允许时，可将图片拖到桌面。拖到微信不保证兼容，推荐「复制图片」后粘贴，或下载后发送。

## 数据与浏览器限制

- API Key 只在当前页面内存中，刷新需重新填写，不保存到 localStorage / IndexedDB。连接检查使用无效测试密钥，不使用真实密钥生成图片。
- API 参数保存在 localStorage。图片和提示词保存在 IndexedDB；不同设备、浏览器和网址不会同步。清除浏览器数据可能删除历史，请下载重要图片。
- 生成时，提示词与选中的参考图会发给你配置的 API 服务商；GitHub Pages 只提供网页文件。
- 服务商必须允许网页跨域请求，包括 Authorization 请求头，以及结果图片的跨域读取。不同 API / 图片 CDN 的支持可能不同。
- 页面中填写 API 地址时不要把 `/v1` 重复添加到地址和接口路径。默认地址不带 `/v1`，默认路径带 `/v1`。
- 「停止等待」会中止本地等待并停止后续提交，无法撤销服务端已接受的任务，服务商可能继续计费。超时和刷新后请先查看服务商记录，再决定重试。
- 保持网页打开直到生成完成。手机切换后台可能暂停网页；无后端版本不承诺后台持续运行。
- 静态网页无法像桌面软件一样打开资源管理器指定目录。目录按钮用于浏览器授权选择目录和写入；不支持时提供普通下载。
- 模型与参数是否可用取决于服务商，本页不保证第三方模型名称对应的实际底层模型。

## 验证

已用 Edge 浏览器模拟响应验证文生图、批量部分失败及单张重试、image[] 多图上传、参考图角色、异步任务、原图下载、历史恢复、密钥不落盘、移动端布局和外部图片域名不携带 API 密钥。

真实服务 `https://www.kuaiaiapi.com` 的浏览器跨域访问已验证：使用无效测试密钥，页面成功读取 HTTP 401。该检查确认浏览器能访问接口，不验证余额、成功图片响应或模型可用性。没有使用用户密钥执行付费生成测试。

开发验证：安装 Playwright 后，启动上述本地服务，再运行 `node verify.cjs`。脚本使用已安装的 Microsoft Edge。也可通过 `PLAYWRIGHT_MODULE` 环境变量指定 Playwright 模块路径。测试截图在被 Git 忽略的 `test-results` 目录中。
